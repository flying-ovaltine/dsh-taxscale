# 申报表穿透与稽查视角（2026 版）

> 用途：换一双眼睛。前面四份文件是"照着规则自查"，这份是"从税务那边看自己"。
> 一句话：财务报表是给银行看的，申报表才是给税务看的。

---

## 1. 为什么必须看申报表

利润表告诉你赚了多少，申报表告诉你**你对税务局说了什么**。

这两者之间一旦对不上，就是风险。而绝大部分企业只看前者，所以永远不知道自己哪里"长得不对"。

举个最典型的：一家公司利润表上营业收入 5000 万，增值税申报销售额 4200 万，差额 800 万。财务的解释是"有一部分是预收款还没发货"。这个解释成立——但需要证据：合同约定的发货时间、库存变动、物流单据。如果这三样凑不齐，800 万就是隐匿收入。

**四层穿透法只能发现"账讲不讲得通"，只有申报表能发现"你报得全不全"。**

---

## 2. 该看哪些表

不是所有表都要看，看这六类就够：

| 表 | 关键信息 | 多久看一次 |
|---|---|---|
| 增值税纳税申报表（一般纳税人适用）及附列资料一至五 | 销售额、销项、进项、留抵、减免 | 每月 |
| 企业所得税年度申报表（A 类）主表及关键附表 | 利润、调整、优惠、弥补亏损 | 每年 5 月 |
| 财务报表报送（三表） | 与申报表的差 | 每季 |
| 个人所得税扣缴申报 | 人数、工资总额 | 每月 |
| 财产和行为税合并申报 | 房产、土地、印花、环保 | 每季 |
| 财务报表附注与明细账 | 解释差异用 | 需要时 |

如果是小规模纳税人，增值税表结构不同，但读数逻辑一样。

---

## 3. 增值税申报表的六个读数点

### 3.1 附表一：销项从哪里来

看的是**税率结构**。9% 的销售额突然变大、13% 的变小，说明业务结构变了，还是把高税率的挪进了低税率？这一栏的变动，是稽查最先看到的信号之一。

### 3.2 附表二：进项长什么样

三件事：

- **进项税率结构**。商贸企业进项全是 13%、销项全是 9%，说明什么？要么是农产品收购（有专门规定），要么是进销不匹配。这个组合几乎必然被问。
- **认证与转出**。有没有该转出的没转（用于福利、免税项目）；有没有把不能抵的抵了（贷款利息、餐饮）。
- **旅客运输、通行费**这类计算抵扣的，计算口径对不对。

### 3.3 主表第 20 栏：期末留抵税额

留抵是"资产"，也是"靶子"。

- 长期大额留抵 + 长期零申报，是最典型的异常组合。
- 申请留抵退税，门槛是纳税信用 A 级或 B 级、且 36 个月无骗税虚开记录。信用一掉，退税通道就关了。
- 留抵退税被查出来不符合条件，是"骗取留抵退税"，性质比少缴税重得多。

### 3.4 减免税明细表：你享了什么

这一栏能反推出你的资格状态。享了小微、享了加计抵减、享了免税——每一项都要有对应条件。

**没享，是可惜；不该享而享，是补税加滞纳金。** 后者才是问题。

### 3.5 差额征税项目

建筑、旅游、劳务派遣、金融商品转让等适用差额的，看扣除额有没有合规凭证。差额扣除没有凭证，等于全额补税。

### 3.6 未开票收入栏

这一栏长期是零，而你的客户又都是企业，就很可疑——企业客户几乎都要票。

未开票收入不是不能有，是要能说清：客户是谁、为什么不要票、怎么收的钱。

## 4. 企业所得税年度申报表的八个读数点

A 类主表是骨架，真正有信息的是这几张附表：

| 附表 | 看什么 | 常见问题 |
|---|---|---|
| A100000 主表 | 利润总额 → 应纳税所得额 | 差异是否都能解释 |
| A101010 收入明细 | 营业收入 vs 增值税销售额 | 差额原因 |
| A104000 期间费用 | 招待费、广宣费、利息 | 是否超限额 |
| A105000 纳税调整 | 调增调减逐项 | 该调没调 |
| A105050 职工薪酬 | 工资、福利、教育经费、工会 | 三项经费限额 |
| A106000 弥补亏损 | 还剩多少、还有几年 | 过期作废 |
| A107040 减免所得税优惠 | 享了哪些 | 资格是否还在 |
| A107012 研发费用加计 | 归集是否规范 | 辅助账缺失 |

### 4.1 四个必查的限额

| 项目 | 限额 | 超了怎么办 |
|---|---|---|
| 业务招待费 | 发生额 60% 与收入 5‰ 孰低 | 调增，永久性差异 |
| 广告和业务宣传费 | 收入 15%（特殊行业 30%） | 调增，可结转以后年度 |
| 职工福利费 | 工资薪金总额 14% | 调增，永久性 |
| 职工教育经费 | 工资薪金总额 8% | 调增，可结转 |
| 公益性捐赠 | 利润总额 12% | 调增，可结转三年 |
| 股东借款利息 | 不超过金融企业同期同类贷款利率 | 超部分调增 |

这些数字每年都在用，但每年都有人算错基数——**基数是"工资薪金总额"，不是"应付职工薪酬"总额，也不含社保和公积金。**

### 4.2 研发费用加计扣除的三个死穴

1. **没有辅助账**。这是被剔除的第一原因，不是费用不真实，是归集不规范。
2. **把不属于研发的算进去**。常规性升级、市场调研、售后服务，都不算。
3. **失败的研发也能加计**——这条很多人不知道，反而少享了。研发失败、未形成成果的支出，只要属于研发活动，一样可以加计。

### 4.3 弥补亏损：最容易白扔的钱

- 一般企业结转 5 年，高新技术企业和科技型中小企业 10 年。
- 过期就作废，不能延。
- 重组时亏损能不能承继，看是否符合特殊性税务处理。

**每年汇算前先看一眼 A106000，快到期的那部分，今年必须想办法用掉。**

## 5. 报表与申报表的七个差异，各自意味着什么

这一节是核心。每一行都是一个"必须能解释"的点。

| 差异 | 常见解释 | 解释不了就是 |
|---|---|---|
| 利润表收入 > 增值税销售额 | 有免税收入、有未开票但已申报、有视同销售未计 | 少报销售额 |
| 利润表收入 < 增值税销售额 | 有预收款已开票、有处置固定资产、有价外费用 | 账外收入 |
| 工资总额 > 个税申报工资 | 有劳务派遣、有非全日制、有离职补偿 | 虚列人工 |
| 个税申报人数 < 社保缴纳人数 | 有退休返聘、有实习、有劳务外包 | 少缴社保 |
| 存货增加但进项很小 | 有暂估入库、有委托加工 | 无票采购、账外经营 |
| 银行流水 > 申报收入 | 有借款、有往来、有股东投入 | 隐匿收入 |
| 房产原值 > 房产税计税原值 | 有在建工程未转固、有免租期 | 少缴房产税 |

**用法**：每年汇算时把这七行拉一遍，每一行写一句解释，能写出来就过，写不出来就去查。这比任何风险清单都直接。

## 6. 稽查不是随机抽的：它用四个老办法从对面算你

这是《纳税评估管理办法（试行）》（国税发〔2005〕43 号）里的通用分析方法，二十年没变，因为有效。

### 6.1 投入产出法

投多少料，该出多少货。

税务机关掌握行业投入产出比，用你的原材料购进量倒推产量，再用产量倒推销量。差出来的部分，就是"没申报的货"。

最常中招的行业：农产品加工、建材、化工、食品、纺织。

**企业该做的**：自己算一遍，如果你的产出率明显高于同行，要么有真技术，要么有账外料。

### 6.2 能耗测算法

用电、用煤、用水，除以单位产品能耗，得出产量。

这条对高耗能行业几乎无解——电表不会说谎。

**企业该做的**：如果你的电费与产值之比突然下降，先想想是不是有未开票收入。

### 6.3 工时（工资）测算法

用生产工时、工资总额倒推产能，再倒推销售。

劳动密集型企业最常被这么算。**个税申报人数、社保人数、工资表人数，三者对不上，就是入口。**

### 6.4 以进控销

买了多少，就该卖多少（考虑库存变动）。

进项发票是全国联网的，你买了什么、从谁那买的，税务机关比你的账还清楚。用进项倒推销项，是最省力的方法。

### 6.5 再加一条：资金流分析法

银行流水与申报收入比对。这一条现在权重最高，因为银税互动、第三方支付数据都已经打通。

**注意**：资金流不是只看对公账户。法人、股东、财务人员的个人账户，如果被认定为经营性收付，一样纳入。

## 7. 金税四期看你的十二个指标

不需要精确到公式，知道"它看什么"就够了。

| 指标 | 什么算异常 |
|---|---|
| 增值税税负率 | 低于行业下限，且连续 6 个月 |
| 所得税贡献率 | 长期接近零 |
| 进销项税率错配 | 进 13% 销 9%、进 9% 销 13% |
| 开票集中度 | 月末最后三天开票占比过高 |
| 作废率 / 红冲率 | 明显高于同行 |
| 顶额开票 | 长期卡在免税额度或起征点附近 |
| 夜间开票 | 非经营时段集中开票 |
| 注册地址聚集 | 同一地址多户、同一法人多户 |
| 关联图谱 | 法人、股东、财务负责人交叉任职 |
| 存货周转率 | 与收入增长背离 |
| 社保/个税人数 | 与经营规模不匹配 |
| 银行流水 | 与申报收入背离 |

### 7.1 税负率怎么算，怎么解释

增值税税负率 = 本期应纳税额 ÷ 本期应税销售额。

拿到这个数之后，做三件事：

1. **跟行业比**。行业均值可以向主管税务机关或行业协会问，也可以在税务局的纳税辅导材料里找。不要拿网上的"预警值"当标准，那些数字大多过期。
2. **跟自己的历史比**。连续下降比单期偏低更危险。
3. **准备"合理性说明"**。三段式：业务结构变化（如新增低毛利大客户）→ 价格与成本变动（如原材料涨价但售价未调）→ 留抵与库存因素（如集中采购备货）。

**说明写得出来，税负率低不是问题；写不出来，低就是问题。**

判断标准只有一条：**你讲的这个故事，能不能被单据证明。**

## 8. 从预警到立案，四个阶段的性质完全不同

很多人把"税务局来电话"和"被立案"当成一回事，应对方式搞错，把小问题做成了大问题。

| 阶段 | 形式 | 性质 | 该怎么应对 |
|---|---|---|---|
| 风险提示 | 电子税务局推送、短信 | 提醒，不是执法 | 自查，能改就改，改完反馈 |
| 纳税评估 / 约谈 | 电话、约谈通知书 | 管理行为，不是检查 | 如实说明，提供资料，可补税 |
| 税务检查 | 税务检查通知书、出示证件 | 执法行为，有法定程序 | 全程留痕，逐项核对，陈述申辩 |
| 立案查处 | 立案决定、处理处罚决定 | 可能涉刑 | 必须请专业人士 |

**最关键的一句话**：评估阶段主动补税，通常只加滞纳金；检查阶段被查出，除了滞纳金还要罚 0.5 到 5 倍。

同一个事实，两个阶段处理，成本可能差一倍以上。这就是"时间窗口"的价值。

## 9. 三个判断，不是三个结论

我能给的是判断，不是结论：

1. **"我的税负率低，会不会被查"**——低本身不是问题，解释不了才是。先做合理性说明，再谈调整。
2. **"这个差异要不要主动说明"**——能自圆其说的，留着证据等问；不能自圆其说的，越早补越好。
3. **"被约谈了要不要请人"**——第一次约谈自己去可以，但不要签任何"确认书"；一旦出现"拟处罚""移送"字样，立刻停手找人。

**边界**：指标体系能告诉你"哪里长得不对"，不能告诉你"会不会被查"。任何声称能预测稽查概率的说法，都是猜的。
