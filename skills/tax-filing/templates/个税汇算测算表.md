## 一、要不要办（先判这一步，不办就别算）

| 情形 | 是否需要办 | 本企业/本人 |
|---|---|---|
| 已预缴 > 应纳，要退税 | **需要**（也可自愿放弃） | □ |
| 综合所得年收入 > 12 万，且需补税 > 400 元 | **需要** | □ |
| 需补税但年收入 ≤ 12 万 | 免于办 | □ |
| 补税金额 ≤ 400 元 | 免于办 | □ |
| 已预缴 = 应纳 | 免于办 | □ |
| 符合退税条件但不申请退税 | 免于办（放弃） | □ |

**"免于办"不等于"不用管"。** 免于办的情形下，如果多缴了，放弃退税就是自己的选择；如果少缴但符合免于办条件，不办也不追责。

## 四、应纳税额

```
应纳税所得额 = 综合所得收入额合计 − 扣除合计
应纳税额 = 应纳税所得额 × 税率 − 速算扣除数
```

| 项目 | 金额 |
|---|---|
| 综合所得收入额合计 | |
| 减：扣除合计 | |
| **应纳税所得额** | |
| 适用税率 | |
| 速算扣除数 | |
| **应纳税额** | |

| 应纳税所得额 | 税率 | 速算扣除数 |
|---|---|---|
| ≤ 36,000 | 3% | 0 |

## 六、容易被漏掉的四笔

| 事项 | 影响 | 依据 |
|---|---|---|
| **大病医疗**未填 | 最多少扣 8 万，多缴几千到两万 | 只能在汇算扣，很多人忘了 |
| **个人养老金**未填 | 少扣 12,000 | 需先在 App 生成缴费凭证 |
| **劳务报酬预扣率过高** | 预扣 20%—40%，汇算按 3%—45% 重算，常常能退 | 多处兼职者最典型 |
| **换购住房退个税** | 出售自有住房后 1 年内同城重新购房，可退出售时已缴个税 | 国家税务总局公告 2026 年第 12 号，执行至 2027-12-31 |

**另有一条 2026 年新增**：按育儿补贴制度发放的育儿补贴**免征个人所得税**（财政部 税务总局公告 2025 年第 6 号，2025-01-01 起），每孩每年 3,600 元，无需自行申报。若系统里已并入收入，可申诉调整。

## 八、自查

- [ ] 收入额换算对了吗（劳务 80%、稿酬 80%×70%）？
- [ ] 减除费用是 60,000（全年任职）？
- [ ] 大病医疗、个人养老金填了吗？
- [ ] 专项附加扣除与配偶/兄弟姐妹分摊没重复？
- [ ] 年终奖选的是单独计税还是并入，算过对比吗？
- [ ] 应补税额是否 ≤400 元（可能免于办）？
- [ ] 退税银行卡是本人 I 类账户？
- [ ] 经营所得是否另有申报（期限 3 月 31 日）？
- [ ] 申报后是否确认提交成功（不是只填了草稿）？
