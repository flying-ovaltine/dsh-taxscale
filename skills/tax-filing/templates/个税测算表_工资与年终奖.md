## 二、累计预扣测算（按月填一行）

公式：
```
本期应预扣 = （累计收入 − 累计免税收入 − 累计减除费用 5,000×月数
             − 累计专项扣除 − 累计专项附加扣除 − 累计其他扣除）
             × 预扣率 − 速算扣除数 − 累计已预扣
```

| 月 | 当月收入 | 累计收入 | 累计减除费用 | 累计专项扣除 | 累计专项附加 | 累计应纳税所得额 | 税率 | 速算扣除 | 累计应扣 | 累计已扣 | 本月扣缴 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | 5,000 | | | | | | | | |
| 2 | | | 10,000 | | | | | | | | |
| 3 | | | 15,000 | | | | | | | | |
| … | | | | | | | | | | | |
| 12 | | | 60,000 | | | | | | | | |
| 合计 | | | | | | | | | | | |

### 税率表（综合所得年度税率，预扣同用）

| 累计应纳税所得额 | 税率 | 速算扣除数 |
|---|---|---|
| ≤ 36,000 | 3% | 0 |
| 36,000—144,000 | 10% | 2,520 |
| 144,000—300,000 | 20% | 16,920 |
| 300,000—420,000 | 25% | 31,920 |
| 420,000—660,000 | 30% | 52,920 |
| 660,000—960,000 | 35% | 85,920 |
| > 960,000 | 45% | 181,920 |

**常见错法：把当月收入单独乘税率，再减速算扣除。** 这样算，年初少扣、年末多扣，全年总额也可能错。累计预扣法的意义就是自动修正——前面少扣的，后面补回来。

## 三、年终奖：两种算法都要算

年终奖金额：____________

### 3.1 单独计税（政策至 2027-12-31，**一人一年只能用一次**）

```
第 1 步：奖金 ÷ 12 = ________
第 2 步：用这个商数查月度税率表（下表）
第 3 步：应纳税额 = 奖金全额 × 税率 − 速算扣除数
```

| 奖金÷12 的商数 | 税率 | 速算扣除数 |
|---|---|---|
| ≤ 3,000 | 3% | 0 |
| 3,000—12,000 | 10% | 210 |
| 12,000—25,000 | 20% | 1,410 |
| 25,000—35,000 | 25% | 2,660 |
| 35,000—55,000 | 30% | 4,410 |
| 55,000—80,000 | 35% | 7,160 |
| > 80,000 | 45% | 15,160 |

### 3.2 并入综合所得

全年综合所得应纳税额（含奖金）− 不含奖金的应纳税额 = 奖金带来的增量税负

### 3.3 两法比较

| 方案 | 计算 | 税额 |
|---|---|---|
| A 单独计税 | | |
| B 并入综合所得 | | |
| **差额** | | **取低者** |

**判定经验**：合并后适用税率会跳档的，单独计税更优；收入低、扣除多、合并后仍在低档的，合并更优。**但个案必须算，不能凭经验。**
