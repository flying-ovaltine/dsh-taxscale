## 1. 增值税（小规模纳税人填此节）

### 1.1 销售额拆分

| 行 | 项目 | 金额 | 校核 |
|---|---|---|---|
| A | 开具增值税专用发票（含税） | | 专票**不免税** |
| B | 开具普通发票（含税） | | |
| C | 未开票收入（含税） | | **确认式申报最容易漏这项** |
| D | 合计含税销售额 | = A+B+C | |
| E | 征收率适用 | 3%（减按 1%） | |
| F | 换算用除数 | ÷(1+1%) | **减按 1% 时用 1%，不是 3%** |
| G | 不含税销售额 | = D ÷ 1.01 | 填主表第 1 行 |

### 1.2 起征点判定

| 项 | 数值 | 结论 |
|---|---|---|
| 申报期免税额度 | 按月 100,000／按季 300,000 | |
| 不含税销售额 G | | |
| 是否超线 | | □ 未超　□ 已超 |
| 处理 | 未超：普票部分填第 10/11 行免税；**专票部分照缴** | 已超：**全额计税，不是超额部分** |

### 1.3 税额计算

| 行 | 项目 | 算式 | 金额 | 对应栏次 |
|---|---|---|---|---|
| H | 应纳税额（按 3% 全额） | = G × 3% | | 主表第 15 行 |
| I | 减征额 | = G × 2% | | 主表**第 18 行** |
| J | 实缴增值税 | = H − I | | 主表第 22/24 行 |
| K | 减免性质代码 | 01011608 | | 减免税明细表 |

**校核句：G × 3% − 第 18 行 = 实缴。对不上说明有栏填错。**

> 若当期未超起征点且全部开普票：H、I、J 均为 0，G 填第 10 或 11 行。
> 若未超起征点但开了专票：仅专票部分计税，`专票不含税额 × 1%`。

### 1.4 一般纳税人填此节（替代 1.1—1.3）

| 项目 | 金额 | 备注 |
|---|---|---|
| 销项税额（13%/9%/6% 分列） | | 混合销售按主要业务定税率 |
| 进项税额（已勾选确认） | | **贷款服务利息不得抵** |
| 进项转出 | | 集体福利、个人消费、免税项目 |
| 加计抵减额 | | 有到期日，逐项核 |

### 4.2 实际利润额（预缴表口径）

| 项目 | 金额 |
|---|---|
| 利润总额（本期累计） | |
| ＋ 特定业务计算的应纳税所得额 | |
| − 不征税收入 | |

**注意：这栏叫"实际利润额"，不叫"应纳税所得额"。** 业务招待费、广宣费、福利费的限额调整**预缴阶段一律不做**，留到汇算。所以两者永远不等。

### 4.3 税额

| 项目 | 算式 | 金额 |
|---|---|---|
| 应纳所得税额 | = 实际利润额 × 25% | |
| 减免所得税额（小微） | = 实际利润额 × 20% | **不填就是按 25% 缴** |
| 实际应纳（累计） | = 上两行之差（小微即 5%） | |
| 减：本年累计已预缴 | | |
| **本期应补（退）** | | |

**小微"335"复查**
| 指标 | 本企业 | 上限 | 判定 |
|---|---|---|---|
| 应纳税所得额 | | 300 万 | **超一分钱整年归零** |
| 从业人数（季度平均值） | | 300 人 | 含劳务派遣 |
| 资产总额（季度平均值） | | 5,000 万 | **不是期末数** |

季度平均值 =（季初 + 季末）÷ 2；全年 = 四季度平均值之和 ÷ 4
